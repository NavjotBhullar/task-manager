## Task Manager API


Create a .env file in the root of the project and add the following variables:

MONGO_URL=''
DB_NAME=''
AUTH_API=''
USER_API=''

Run the Project

Start the FastAPI server:

uvicorn main:app --reload --port 3001

## API Documentation

After running the server open:

http://127.0.0.1:3001/docs
